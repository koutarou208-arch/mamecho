# まめ帳 家計簿 ― 仕様書

マネーフォワード ME や Moneytree のような「お金の流れをまとめて見る」家計簿アプリです。
銀行やカードとの自動連携はできないので、そのかわりに **手入力・CSV取り込み・レシート読み取り** でデータを集めます。

---

## 1. だれのためのアプリか

- 自分ひとり（または自分の家計）のお金を管理したい人
- 銀行・カード・電子マネー・証券・ポイントの残高を1か所で見たい人
- クレジットカードの「いつ・いくら引き落とされるか」を把握したい人

## 2. 画面の一覧

| 画面 | できること |
|---|---|
| ホーム | 総資産とその推移、資産の内訳、今月の収支と予算の使い具合、カードの引き落とし予定、支出の内訳、最近の入出金 |
| 入出金 | 期間内の記録を日付ごとに一覧。口座・カテゴリ・種類・言葉で絞り込み。行を押すと編集 |
| 家計簿 | 1年分の収支グラフ、カテゴリ別（先月との差・3か月平均・中項目の内訳）、固定費と変動費、毎月の支払い・サブスクの自動検出、日ごとの支出カレンダー、AIのふり返り |
| 予算 | カテゴリごとの予算と使い具合（順調・注意・超過）、今日までのペースの目安線、貯金目標 |
| カード | カードごとの次の引き落とし、引き落とし口座の残高チェック、分割・リボ・スキップ払いの残り、これからの請求の一覧と内訳 |
| 口座 | 種類ごとの口座と残高。押すと通帳ふうの明細、残高修正 |
| 手取り | 額面（1か月の総支給額）を入れると、社会保険料・所得税・住民税と手取りをすぐに計算（毎月・ボーナス・1年）。スマホは上のバーの電卓ボタン、パソコンは左のメニューの「手取り計算」から |
| 設定 | 1か月の始まりの日、CSV・バックアップ、自動分類ルール、保存先、全削除 |

## 3. データの決まりごと

### 入出金の種類

| 種類 | 意味 | 収支に入るか |
|---|---|---|
| 支出 | お金を使った | 入る |
| 収入 | お金が入った | 入る |
| 振替 | 自分の口座どうしの移動（ATMで引き出す、チャージする、カードの引き落とし など） | 入らない |
| 残高修正 | アプリの残高を実際の残高に合わせるための差額（証券の評価額の更新など） | 入らない |

「収支の計算に含める」を外すと、立替金などを収支から外せます（残高には反映されます）。

### カテゴリ

マネーフォワード ME と同じような「大項目・中項目」の2段階です。
支出16種類・収入6種類。一覧は `js/01-categories.js` にあります。
住宅・水道光熱費・通信費・保険・税は「固定費」として扱います。

### 口座の残高の考え方

口座を登録するときに「基準日」と「その日の朝の残高」を入れます。
- 基準日以降の入出金 → 足し引きして今の残高を計算
- 基準日より前の入出金（過去の明細をCSVで取り込んだ場合など） → すでに残高に含まれているとみなす

カード・ローンは「負債」なので、残高はマイナス（借りている額）になります。

### 1か月の区切り

設定で「1か月の始まりの日」を1〜28日から選べます。
25日にすると「10月度」＝ 10/25〜11/24 のように、給料日を区切りにできます。

### スマホでの操作感

- 「記録する」は、スマホでは下のタブのすぐ上の右に浮かぶ丸い「＋」ボタン（親指が届く所）。パソコンでは上のバーのまま。
- 入出金の画面は、検索と「絞り込み」ボタンが1行。口座・カテゴリ・種類はボタンを押すと出る（絞り込み中は「絞り込み（1）」のように数を出して、はじめから開く）。カード利用メールからの記録は「記録する」の中から。
- スマホのホームは、毎日見るものを上に並べる: 今月の収支と予算 → 総資産 → 株の利益の安心ライン（見出しと記録ボタンだけ。くわしくは開いて見る。アウトのときは最初から開く）→ カードの引き落とし → 最近の入出金 → 資産と支出の内訳。

- 金額が重ならないようにする: スマホでは「資産・負債・純資産」などの数字を横に3つ並べず、1行に1つ「名前 … 金額」で出す。家計簿のカレンダーの小さいマスには、短い金額（1.3千・1.4万など）を出す（押すと、その日の明細でふつうの金額が見られる）。
- 画面が勝手に拡大・縮小しないようにする: 入力欄の文字はすべて16px（これより小さいと iPhone が押したときに拡大する）、画面の幅からはみ出す部品を作らない（はみ出すと iPhone が全体を縮小する。長い文字のボタンは折り返す）、2回トンと押したときの拡大はしない（指2本での拡大はできる）。iPhone SE（幅320）〜でも、全画面とダイアログではみ出しがないことを確かめている。
- 下のタブは、今いる場所の印が横にすべって移る。押すと少しへこむ。
- 画面を切りかえても点滅しない（下のメニューのボタンは作り直さず、印だけ付けかえる）。月を切りかえたときだけ、横にすべって入ってくる（「動きを減らす」設定の人には動かさない）。
- 期間のある画面（ホーム・入出金・家計簿・予算など）は、画面を左右になぞると前の月・次の月へ動く
  （入力欄・グラフ・表の上では動かさない）。判定は `03-helpers.js` の `swipeStepOf`。

### 株の利益の安心ライン（ホーム）

- 「投資をのぞいた収支」（収入 − 投資の利益 − 生活費の支出）から、安心ラインに届くために**株でいくらの利益が必要か**を出す。
- 安心ライン: 毎月の貯金目標があればそれ。なければ「赤字にならないこと」。
- 表示: 「株なしで安心」「利益で安心」「あと ¥○○」の3段階と、直近3か月の平均をもとにした「ふだんの月に必要な利益」。
- 自分の記録だけを使った計算で、個別の銘柄や売買のおすすめはしない。
- 表示場所: ホームの一番上の「総資産」のすぐ下に、独立したカードとして大きく出す。記録が1件もない期間でも出す（「記録待ち」と表示）。
- **アウトのルール**: 支出（投資の損失はのぞく）が給与でまかなえなくなったら「アウト」（赤い札・赤い枠）。株の利益が出ていても、アウトはアウト。
  - 給与は大項目「給与」の収入。今月まだ給与が入っていないときは、直近3か月の給与の平均で見る。
  - 給与の記録が全くないときは、判定しない（アウトにしない）。
- 日ごとの推移: 期間の最初の日から今日まで、1日ずつ「必要な株の利益」と「株の損益（累計）」を折れ線で出す。「日ごとに見る」で表も開ける（日付・株をのぞく収支・株の損益・必要な利益）。

### スマホのアプリ（ホーム画面に追加）

- アプリ名「まめ帳」、アイコンはロシアンブルーの猫（`icons/`）。全画面で開く（`manifest.webmanifest`）。
- 電波が弱くても開ける（`sw.js` が本体のファイルを覚えておく）。家計簿のデータそのものは、その端末のブラウザに保存される。
- 自分のサイト（https）で開いたときだけ有効。Claude の中で開いているときは使わない。
- 端末を変えるときは、設定の「別のスマホ・アプリへ移す」の「文字でコピー」で、バックアップの文字をコピーし、新しい端末で「貼り付けて戻す」に貼り付ける（ファイルを扱わなくてよい）。ファイルで書き出す「バックアップ」の「保存」「戻す」も使える。

### 安全のための作り（情報を外に出さない）

- **アプリは、自分のファイル（同じサイトの中）以外とは通信しない。** index.html の Content-Security-Policy で、外への送信・よそのプログラムや文字（フォント）の読み込みをブラウザに禁止させている。プログラムにまちがいがあっても、外には送られない。
  （Claude の中で開くときは、Claude の仕組みの中で動く。レシート読み取り・AIのふり返りは、押したときだけ Claude に送る。送るのはレシートの画像と、集計した数字だけ）
- 文字（フォント）は端末に入っているもの（iPhone はヒラギノ）を使う。外からは読み込まない。
- 家計簿のデータは、その端末のブラウザの中（Claude の中なら自分専用の保存場所）にだけある。暗号化ロックをオンにすると、保存する前に暗号化する。
- バックアップ（ファイル・文字でコピー）は、自分で押したときだけ作られる。中身はそのままなので人に見せない。
- 以前の版にあった「Gmail から自動で記録」の鍵（合言葉と URL）は、読み込み時に捨て、書き出しにも入れない。
- 画面に出す文字は必ず escapeHtml を通す。CSV に書き出すとき、「= + - @」で始まる文字は式にならないよう先頭に ' を付ける。

### カード利用通知メールから記録

- 入出金を記録する画面の「カード利用のメールから入力」、または入出金の一覧の「カード利用のメールから記録」から使う。
- JCBなどの利用通知メールの文章を貼り付けると、日付・金額・ご利用先・カード（口座）を自動で入力する。内容を確かめて保存する。
- 読み取るのは「ご利用日時」「ご利用金額」「ご利用先」「カード名称」の行。メールの文章は端末の中だけで読み取り、どこにも送らない。
- 完全な自動（メールが届いたら勝手に記録）は、安全のため作らない（Gmail を外から読む仕組みが必要になり、情報が漏れる入り口になるため。一度作ったが取りやめた）。貼り付けが最小の手間。

### 固定費（家賃などを毎月自動で記録）

- 設定の「固定費（毎月自動で記録）」で、名前・金額・毎月の日（31は月末）・カテゴリ・口座・いつの月からを登録する。
- アプリを開いたとき、指定日が来ている月の分が、入出金として自動で記録される。まだ来ていない日の分は作らない。
- 固定費ごとに「どの月まで記録したか」を覚えているので、同じ月を2回記録しない。記録した分を消しても、作り直されない。
- 同じ月に、同じ内容・同じ金額の支出を手で先に入れてあるときは、二重に記録しない。
- 金額を直したときは、これからの月から新しい金額になる（記録ずみの月はそのまま）。
- 家計簿の「毎月の支払い・サブスク」（自動で見つけたもの）から、「固定費にする」で登録することもできる。
- サンプル表示中・ロック中は記録しない。

### 手取り計算

- 入れるのは **額面（1か月の総支給額。交通費もふくむ）だけ**。「30万」のような書き方もできる。入れたそばから結果が出る。
- 見やすさと操作感:
  - 金額の欄は、打ちながら3けたごとにカンマが入る（「300000」→「300,000」）。
  - 額面の下の「つまみ（スライダー）」を左右に動かすと、5万〜100万円の間で額面が変わり、結果がその場で動く。
  - 手取りの大きな数字は、前の数から新しい数へなめらかに動く。
  - 毎月の結果に「立体の積み上げ柱」を出す（下から 手取り・社会保険料・税金）。高さは額面に対する割合。左右になぞると回り（離すと少しすべって止まる）、キーボードなら ← →。段やとなりの説明にさわると、その段だけ目立つ。3Dのライブラリは使わず、角の点を計算して SVG で描く（`js/07-charts.js` の `createMoneyColumn3d`）。
  - 「額面が1万円増えると、手取りは +◯円」も出す（標準報酬月額の段が上がると、保険料も上がるので増え方は一定ではない）。
  - 7項目の内訳は「くわしい内訳」を開くと見られる（ふだんは3つの合計だけ）。
  - 打っている途中で額面が5万円より小さいあいだは、前の結果をうすくして残す（画面がガタつかないように）。
  - 端末で「動きを減らす」設定になっているときは、数字や柱を動かさずに、すぐ最後の形を出す。
- 「条件」を開くと、年齢（40歳未満・40〜64歳・65〜69歳・70歳以上）、都道府県、ボーナス（年間の合計）、うち交通費、扶養（配偶者・16歳以上の子や親の人数）を変えられる。はじめは「40歳未満・東京都・扶養なし・ボーナスなし」。
- 出すもの: 毎月の手取りと内訳（健康保険・介護保険・子ども子育て支援金・厚生年金・雇用保険・所得税・住民税）、ボーナスの手取り、1年の手取り。
- 計算のもと（2026年度）:
  - 健康保険・介護保険・支援金・厚生年金は、額面を表に当てはめた「標準報酬月額」に料率をかける。健康保険は協会けんぽの都道府県ごとの料率（令和8年3月分から）、介護保険 1.62%（40〜64歳）、支援金 0.23%、厚生年金 18.3%（すべて会社と半分ずつ）。本人の分の端数は「50銭以下は切り捨て、50銭より多ければ切り上げ」。
  - 雇用保険は額面（交通費もふくむ）の 0.5%（一般の事業・令和8年度）。
  - ボーナスは2回に分けて払われるとして、1000円未満を切り捨てた額に料率をかける（健康保険などは年573万円まで、厚生年金は1回150万円まで）。
  - 所得税は2026年分のきまり（基礎控除 104万円〜、給与所得控除の最低 74万円など。国税庁「源泉所得税の改正のあらまし（令和8年4月）」）で1年分を出し、復興特別所得税 2.1% を足す。毎月の欄は、ボーナスがなかったときの1年分を12で割った額。ボーナスで増えた分はボーナスの欄に出す。
  - 住民税は所得割 10%（調整控除あり）と均等割 5,000円（森林環境税をふくむ）。1年分を12で割って毎月の欄に出す。所得が少なくて非課税になる線は、大きな市（1級地）のもの。
  - 交通費は、社会保険料にはふくめ、税金はかからない分（月15万円まで）として計算する。
- 目安であること: 会社の健康保険組合、住宅ローン控除・医療費控除などの控除、所得金額調整控除、16歳未満の子どもによる住民税の非課税の線の変化は入れていない。毎月の所得税は実際の天引き（源泉徴収税額表）と少しちがい、差は年末調整で精算される。住民税は前の年の収入にかかるので、働きはじめた年は引かれない。
- 入れた額面は、アプリを開いている間だけ使う。家計簿のデータにも保存せず、どこにも送らない。
- 料率は年に1回見直す（3月: 健康保険・介護、4月: 雇用保険・支援金、12月: 税制改正）。見直す日（2027年3月1日）をすぎると、画面に「新しい料率に変わっているかもしれません」と出る。

### 記録した値の修正

- 入出金: 一覧・ホーム・口座の通帳（明細の行を押す）から、どれでも開いて直せる。削除もできる。
- 月の支払い金額だけ入力したもの（カード）: 一覧の行を押して金額や日付を直せる。
- 自動分類ルール: 設定の「直す」でキーワード・カテゴリを直せる。
- 予算・口座・カードの設定: それぞれの「編集」「口座の設定」から直せる。

### 株式投資の損益

- いちばん簡単な記録のしかた: ホームの「株の利益の安心ライン」カードにある「株の利益を記録」「株の損失を記録」ボタン（証券口座があれば自動で選ぶ）。
- 株式などの売買で出た利益は収入の「投資の利益」、損は支出の「投資の損失」として記録する（入出金の記録で選ぶ）。
- **収支（黒字・赤字）にはふくまれる。** ホームの「今月の収支」に、投資損益だけの数字も出る。
- 投資の損失は生活費ではないので、**予算の「使った金額」にはふくめない**（予算の画面・ホームの予算バー・固定費と変動費）。
- 「売却益」「損切り」などの言葉は、内容から自動でこれらのカテゴリに分類される。

## 4. クレジットカード

カードは何枚でも登録できる（1枚ごとに締め日・支払日・引き落とし口座・支払い方法を持つ）。カード画面の「カードを追加」、または口座画面の「口座を追加」で種類を「クレジットカード」にする。2枚以上あるときは、カード画面の上に全カードの次の引き落とし合計を出す。

### 対応しているカード会社（初期値つき）

JCB / 三井住友カード / 楽天カード / イオンカード / セゾンカード / エポスカード / 三菱UFJカード / NICOSカード / dカード / au PAY カード / PayPayカード / アメリカン・エキスプレス / ビューカード / オリコカード / ジャックスカード / UCカード / ライフカード / その他（自分で設定）

会社ごとに次の初期値を持っています（`js/02-card-companies.js`）。
- 締め日と支払日（複数のパターンがある会社は選べる）
- ボーナス払いの利用期間と支払月
- 使える支払い方法
- 手数料率（分割・リボ・スキップ払い・ボーナス2回払い）
- 登録型リボの名前（JCB「支払い名人」、三井住友「マイ・ペイすリボ」、楽天「自動リボサービス」）

> 数字は2026年10月時点で各社の公開情報をもとに調べた目安です。会社がルールを変えることもあるため、カードの設定画面からカードごとに上書きできます。

### 支払い方法と計算方法

| 支払い方法 | 計算 |
|---|---|
| 1回払い | 締め日までの利用分を、支払日に全額 |
| 2回払い | 半分ずつ2か月。手数料なし |
| ボーナス一括払い | 利用日がボーナス払いの期間内なら、夏（多くは8月）か冬（多くは1月）の支払日に全額。期間外は1回払い扱い |
| ボーナス2回払い | 夏と冬に半分ずつ。手数料は「100円あたり◯円」 |
| 分割払い | 3〜36回。元利均等方式（毎月ほぼ同じ額）で手数料を計算 |
| リボ払い | 毎月決まった元金（初期値1万円）を返済。前月から残っている元金に「年率÷12」の手数料 |
| スキップ払い（JCB） | 1回払いの支払月を1〜6か月先へ。手数料＝利用額×月利×ずらした月数（2026年10月以降の利用分は月利1.50%） |
| 登録型リボ | カードの設定でオンにすると、1回払いの利用もリボとして計算 |

### 月の支払い金額だけを入れる

買い物を1件ずつ記録しなくても、カード画面の「月の支払い金額だけをまとめて入力する」から「2027年1月に150,000円」のように合計だけを入れられます（JCBのスキップ払いの確定額など）。
- 入れた金額はカードの残高（負債）に足され、請求の一覧にも「手入力の支払い予定」として入ります。
- 同じ月にもう一度入れると上書き、一覧の✕で削除できます。
- カード画面の「これから払う金額（月別）」グラフで、月ごとの引き落とし額（元金・手数料）と、その月のあとに残る負債をマウスをのせて確認できます。

### 請求と引き落とし

- 請求は「何月の何日に、元金いくら＋手数料いくら」の単位でまとめます。
- 締め日を過ぎた請求は「確定」、まだのものは「未確定」と表示します。
- 「この引き落としを記録する」を押すと
  - 元金 → 引き落とし口座からカードへの「振替」
  - 手数料 → 引き落とし口座からの「支出」（その他／カード手数料）
  として記録され、残高に反映されます。
- 引き落とし口座の残高が次の請求額より少ないと「残高不足」と表示します。
- 支払日を過ぎても記録されていない請求は「未記録」と表示します。
- 土日祝日で支払日がずれることは計算に入れていません。

## 5. データを集める方法

1. **手入力** … 金額欄は「1200+380」のような計算もできます。内容（お店の名前）からカテゴリを自動で選び、自分で直すとそのお店のルールを覚えます。
2. **CSV取り込み**（どの銀行・カードの明細でも）
   - 文字コードは Shift_JIS / UTF-8 を自動判定。CSV の読み取りは PapaParse（`js/vendor`、外とは通信しない）。区切り（カンマ・タブ）や、"" で囲んだ中のカンマ・改行も読めます。
   - 見出しの前の説明の行（「○○カード ご利用明細」など）は読み飛ばします。見出しから日付・摘要・金額の列を推測します（選び直せる）。
   - カードの明細（プラス＝支払い）は、見出しの名前（利用金額・利用店など）か、金額のほとんどがプラスかで見分けます。
   - 金額は文字から**整数（円）**で読みます（小数で計算しない）。「△1,200」「(1,200)」「1,200-」はマイナス。「1200.00」は 1200。小数の金額（外貨など）や読めない金額は取り込まず、何行目か・理由を一覧で出します。
   - 取り込む前に、このファイルの明細の**件数と合計（支出・収入・差し引き）**を出します。「ご利用合計」などの合計の行があれば、計算した合計と1円まで一致するかを自動で確かめます（合計の行は明細には入れない）。
   - 重複: **同じ口座・同じ日付・同じ金額・同じ摘要**（全角半角・空白のちがいはそろえる）の明細が、すでにある数だけ飛ばします。同じ日に同じ店で同じ金額を2回使った明細は2件とも入り、同じファイルを取り込み直しても増えません。
   - マネーフォワード ME の入出金履歴CSVはカテゴリと金融機関まで読み取ります。
   - マネーフォワード ME の形（このアプリの「CSVで書き出す」も同じ形）は、支出がはじめからマイナスなので、＋−をひっくり返さない。書き出したCSVを取り込み直しても、向き・費目・件数は変わらない。
   - 取り込みには印をつけるので、設定の「前回の取り込み → 取り消す」で、その取り込みで入った明細だけを消せる（確認あり）。
   - 前の版で＋−が逆のまま入った明細（同じ日・金額・内容・口座で収入と支出が1件ずつ）は、設定に「向きが逆に入った明細」として出し、あとから入った方だけを消せる（一覧を見てから、確認して消す）。
3. **レシート読み取り**（Claude 上で開いたときだけ） … 写真から日付・お店・金額・カテゴリを読み取ります。

## 6. 保存

| 開き方 | 保存先 |
|---|---|
| Claude のアーティファクトとして開く | その人の Claude アカウント（本人専用。リンクを共有しても他の人には見えない） |
| `index.html` をブラウザで直接開く | そのブラウザの中（localStorage） |
| どちらも使えない | 保存しない（閉じると消える） |

データは「設定（profile）」1つと「月ごとの入出金」に分けて保存します。
初めて開いたとき（まだ何も保存されていないとき）は、架空の1年分の **サンプル** を表示します。サンプルは保存されません。

## 7. 書き出し

- **CSV**: マネーフォワード ME に近い列（計算対象, 日付, 内容, 金額（円）, 保有金融機関, 大項目, 中項目, メモ, 振替, 支払い方法, ID）。Excel で文字化けしないよう UTF-8（BOM付き）。
- **バックアップ（JSON）**: 口座・予算・設定・ルールもふくめて丸ごと。「戻す」で復元できます（今のデータは置きかわります）。

## 8. AIの機能（Claude 上で開いたときだけ）

- レシートの読み取り
- 今月のふり返り（良かった点・気になる点・来月できること）。送るのは集計した数字だけで、お店の名前などは送りません。金融商品のおすすめはしません。

使うと、見ている人の Claude の利用枠を使います。最初に確認が出ます。

## 9. 制度データの自動更新とお知らせ

- カード会社のデータ（締め日・支払日・ボーナス払い・手数料率）は `js/02-card-companies.js` に集めてあり、**毎月1回**、Claude の定期タスクが各社の公式ページを確認して更新します（手順は `tools/UPDATE_RULES.md`）。
- 手数料率は「いつから何%か」を日付つきで持ち、**買い物をした日**で率を選びます。たとえばJCBは9月30日までの買い物は旧率、10月1日以降は年18%です。今後の改定予定も先に入れておけます。
- 会社ごとに「確からしさ」を持ちます（公式ページで確認／解説サイトなどの情報／推定）。
- 制度が変わったときは、自分が登録しているカードの会社に関する変更を、画面の上部にお知らせします（「読んだ」を押すまで）。開始日が未来の変更は「これから変わります」と出ます。
- 最後に公式ページを確認してから45日以上たつと「データが古いかもしれません」と出ます。
- 設定画面の「制度データ」に、データのバージョン・確認日・変更の履歴（出典つき）・各社の確からしさが載っています。
- 数字が実際の明細とちがうときは、カードの設定で手数料率などを自分で上書きできます。

## 10. セキュリティ

| 対策 | 内容 |
|---|---|
| 本人だけの保存領域 | Claude のアーティファクトで開くと、データは自分専用の領域に入り、ほかの人は読めません（Claude 側の仕様） |
| 暗号化ロック（任意） | 設定でオンにすると、保存の直前にパスフレーズで暗号化（AES-GCM 256bit、鍵はPBKDF2-SHA256 60万回で作る。保存のたびに新しい乱数を使う）。保存先には暗号文しか残らず、運営側やページの作者にも読めません。パスフレーズは8文字以上（12文字より短い・数字だけ・同じ文字のくり返しは注意を出し、もう一度押せば使える）。解除のときは全角・半角のちがいを気にしなくてよい（両方試す） |
| 自動ロック | 暗号化ロックがオンのとき、10分操作しないと自動でロックし、メモリのデータも消します |
| Face ID・指紋で開く（任意） | ホーム画面のまめ帳（アプリ版）で、暗号化ロックがオンのときに設定できる。パスキー（Face ID で守られた鍵）の PRF で取り出せる秘密の数から鍵を作り、パスフレーズを暗号化してこの端末にだけ保存する。Face ID を通らないと元に戻せない。バックアップ・ほかの端末には入らない。ロックをオフにすると記録は消える。Claude の中では使えない。iPhone は iOS 18 以降。登録してあれば、ロック画面が出たとき（アプリを開いたとき・裏から戻ったとき）に自動で Face ID が始まる。やめたり通らなかったりしたときは勝手にくり返さず、大きな「Face ID で開く」ボタンかパスフレーズで開く。Face ID が出ないときは、ロック画面にその理由を出す（Claude の中で開いている・この端末ではまだ登録していない・使えない端末）。まだ登録していない端末でパスフレーズで開くと、「次から Face ID で開けるようにしますか？」と聞き、1回押せば登録できる（「今はしない」を押したら、その端末ではもう聞かない。設定からはいつでも登録できる）。ロックをオンにした直後も、打ったばかりのパスフレーズでそのまま登録できる |
| まちがえて消さない | データをすべて消す操作（ロック画面の「パスフレーズを忘れたとき」・設定の「すべてのデータを削除」）は、「削除」（または「さくじょ」）と入力するまで消すボタンが押せない。ロック画面では、開くボタンから離していちばん下に置く |
| ロック中は何も見せない | ロック中は画面にも保存にもデータを出さず、パスフレーズ入力を閉じられません |
| 個人情報を外に出さない | 不具合の報告文には金額や名前を入れません。AIには集計した数字だけを送ります |
| 画面への出力 | ユーザー入力・CSVの文字は必ず無害化して表示します |

**守れないこと:** パスフレーズを忘れたとき（だれにも復元できません）、弱いパスフレーズ（暗号文を盗まれると総当たりで当てられる）、書き出したCSV・バックアップのファイル（暗号化されません）、ロックを解除している間の画面のぞき見、ロック解除中にスマホごと使われること。

## 11. 実装の修正のしくみ

- 自動テスト（`sh tests/run.sh`）… カードのデータの形、日付と手数料率の引き方、請求の計算、CSV・金額の読み取り、手取り計算（協会けんぽの保険料額表・国税庁の表と同じになるか）を確かめます。
- `CLAUDE.md` … 直し方の流れ（テストを先に書く → 直す → 全テスト合格 → 動作確認 → 公開）と約束ごと。
- 設定画面の「不具合・数字のちがいを報告する文をコピー」… 個人の金額が入らない状態の情報をコピーして、Claude に貼り付けられます。

## 12. できないこと（今後の候補）

- 銀行・カード会社との自動連携
- 土日祝日による支払日のずれ
- 複数人での家計の共有
- 外貨
- 収入（給料など）の毎月の自動記録（固定費の自動記録は支出だけ）
