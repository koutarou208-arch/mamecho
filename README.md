# まめ帳 家計簿 ― はじめに読んでね

このフォルダには家計簿アプリ「まめ帳」の部品がすべて入っています。
プログラミングをしたことがなくても読めるように、どのファイルにも日本語の説明を書いてあります。
アプリの機能の説明は [docs/仕様書.md](docs/仕様書.md) を見てください。

---

## 1. 動かし方

- **いちばんかんたん**: `index.html` をダブルクリックしてブラウザで開く。
  データはそのブラウザの中に保存されます。
- **Claude で公開したもの**: もらったリンクを開く。
  データはあなたの Claude アカウントに保存されます（本人専用）。

インストールや準備は何もいりません。

---

## 2. Webアプリは3種類のファイルでできている

| 種類 | 役割 | たとえると | このアプリでは |
|---|---|---|---|
| HTML | 画面に何を置くか | 家の間取り | `index.html` |
| CSS | どう見せるか（色・大きさ・並べ方） | 内装・ペンキ | `style.css` |
| JavaScript（JS） | どう動くか（計算・ボタンを押したときの動き） | 電気・水道 | `js/` フォルダの23個のファイル |

## 3. ファイルの地図

`js/` のファイルは **番号の順に読み込まれます**。番号が小さいほど「土台」で、大きいほど「土台を使う側」です。

```
mamecho/
├─ index.html ……………… 画面の骨組み（メニュー・入力ダイアログ）
├─ style.css ………………… 見た目（いちばん上に色の一覧があります）
├─ CLAUDE.md ……………… Claude 向けの案内（直し方・約束ごと）
├─ docs/仕様書.md ………… アプリの仕様
├─ tests/ …………………… 自動テスト（sh tests/run.sh で実行）
└─ tools/UPDATE_RULES.md … 毎月のデータ見直しの手順書
   js/
   ├─ vendor/ ……………… 【よその部品】PapaParse（CSVを読む）。中身は書きかえない（vendor/README.md）
   ├─ 01-categories.js ………… 【辞書】カテゴリ・口座の種類・自動分類ルール
   ├─ 02-card-companies.js …… 【辞書】カード会社の締め日・支払日・手数料
   ├─ 03-helpers.js …………… 【道具】金額や日付を扱う小さな関数
   ├─ 04-state-and-storage.js 【記憶】アプリの状態と、データの保存
   ├─ 05-calculations.js ……… 【計算】残高・収支・期間・自動分類
   ├─ 06-credit-card-billing.js【計算】カードの請求（分割・リボなど）
   ├─ 07-charts.js …………… 【部品】グラフを描く
   ├─ 08〜14-screen-○○.js …【画面】ホーム／入出金／家計簿／予算／カード／口座／設定
   ├─ 15-dialog-transaction.js【画面】入出金の入力ダイアログ
   ├─ 16-dialog-account.js …… 【画面】口座の設定と、通帳ふうの明細
   ├─ 17-csv-and-backup.js …… 【機能】CSVの取り込み・書き出し、バックアップ
   ├─ 18-ai-features.js ……… 【機能】レシート読み取り、AIのふり返り
   ├─ 19-sample-data.js ……… 【機能】お試し用のサンプルデータ
   ├─ 20-rules-alerts.js …… 【機能】制度変更のお知らせ、不具合の報告文
   ├─ 21-encryption-lock.js 【機能】暗号化ロック（パスフレーズ）
   ├─ 22-take-home-pay.js …… 【機能】手取り計算（社会保険料・税金の料率と計算・画面）
```

## 4. データの流れ（いちばん大事なしくみ）

アプリの中では、いつも次の順番で物事が進みます。

```
① ボタンを押す
      ↓   （23-app-start.js の ACTIONS が受け取る）
② データを変える
      ↓   （04 の putTransaction など）
③ 計算し直す → 保存する → 画面を描き直す
          （04 の afterDataChange がまとめてやる）
```

画面は「データから毎回作り直す」方式です。
画面を直接書きかえるのではなく、**データ（appState）を変えて renderApp() を呼ぶ** のが基本です。
こうしておくと「画面とデータが食い違う」という種類のバグが起きにくくなります。

### appState（アプリの記憶）の中身

`04-state-and-storage.js` の最初にあります。

| 名前 | 中身 |
|---|---|
| `profile` | 設定・口座・予算・自動分類ルール |
| `monthly` | 入出金。`{ '2026-09': [...], '2026-10': [...] }` のように月ごとの箱に分けて入れている |
| `screen` | 今表示している画面の名前 |
| `period` | 表示中の期間（例: `{ year: 2026, month: 10 }`） |
| `filters` | 入出金画面の絞り込み条件 |

入出金1件の形は `05-calculations.js` の最初に書いてあります。

## 5. よくある変更のやり方

### カテゴリを増やしたい

`js/01-categories.js` の `EXPENSE_CATEGORIES`（支出）か `INCOME_CATEGORIES`（収入）に1行足します。

```js
{ id: 'pet', name: 'ペット', mark: 'ペ', subs: ['フード', '病院', 'トリミング'] },
```

- `id` は英数字で、ほかと重ならない名前に。**一度使い始めたら変えない**でください（保存データがこの名前を使っています）。
- `name`（表示名）はあとから変えてもOKです。

### お店の自動分類を増やしたい

`js/01-categories.js` の `BUILT_IN_RULES` に1行足します。

```js
{ type: 'expense', words: ['まるみや', 'マルミヤ'], category: 'food', sub: '食料品' },
```

アプリの設定画面からも追加できます（そちらはあなたのデータに保存されます）。

### カード会社の数字を直したい／会社を増やしたい

`js/02-card-companies.js` の `CARD_COMPANIES` を書きかえます。
書き方は同じファイルの上の説明を見てください。`STANDARD_BONUS` は「夏は8月・冬は1月払い」のよくある型です。

### 色を変えたい

`style.css` のいちばん上の `:root { ... }` の中だけを書きかえます。
`--accent` がアプリの基本の色（今は帳簿の緑）です。
ダークモードの色はそのすぐ下に2回（同じ内容）書いてあるので、両方そろえて変えてください。

### 新しいボタンを作りたい

1. HTML に `data-action="my-button"` を付けたボタンを書く
2. `js/23-app-start.js` の `ACTIONS` に同じ名前で「すること」を書く

```js
'my-button': () => showToast('押されました'),
```

## 6. 毎月の自動更新・テスト・直し方

### カードのデータ（手数料率など）の自動更新

- 毎月1日の朝に、Claude の定期タスクが `tools/UPDATE_RULES.md` の手順で各社の公式ページを確認し、
  変わっていたら `js/02-card-companies.js` を書きかえて公開します。
- 変わったことは、アプリの上部に「制度が変わります」とお知らせされます（「読んだ」を押すまで）。
- 最後の確認から45日以上たつと「データが古いかもしれません」と出ます（自動更新が止まったときの見張りです）。
- 設定画面の「制度データ」で、バージョン・確認日・変更の履歴・各社の確からしさが見られます。
- 自動更新はパソコンのClaudeアプリが起動していて、スリープしていないときに動きます。

### テスト

```bash
sh tests/run.sh
```

「すべて合格です」と出れば、カードのデータの形・日付と手数料率の引き方・請求の計算・CSVの読み取りが正しい状態です。
`js/` の計算部分を直したときと、データを更新したときは、必ず実行します。

### 実装を直したいとき

1. おかしいところを Claude に伝える（設定画面の「不具合・数字のちがいを報告する文をコピー」を貼ると早い）
2. Claude が `CLAUDE.md` の流れ（テストを先に書く → 直す → 全テスト合格 → 動作確認 → 公開）で直します

## 7. 用語集

| 用語 | 意味 |
|---|---|
| 関数（function） | 「受け取ったものから結果を作る」ひとまとまりの処理。`function formatYen(amount) { ... }` |
| 変数（const / let） | 値に名前を付けて覚えておく箱。`const` は中身を入れかえない箱、`let` は入れかえる箱 |
| 配列 `[ ]` | 順番に並んだリスト |
| オブジェクト `{ }` | 「名前: 値」の組み合わせ |
| `if` / `for` | 「もし〜なら」／「〜の数だけくり返す」 |
| `async` / `await` | 時間のかかる処理（保存・通信）が終わるのを待つための書き方 |
| DOM | ブラウザが画面の部品を管理している仕組み。`findOne('#screen')` で部品を探せる |
| イベント | 「押された」「入力された」などの出来事。`addEventListener` で受け取る |
| SVG | 線や四角を座標で描く画像の形式。グラフに使っている |
| CSV | カンマで区切った表のファイル |
| JSON | プログラムでよく使うデータの書き方（バックアップに使っている） |
| localStorage | ブラウザの中にデータを保存する仕組み |

## 8. 安全のための約束（コードの中で守っていること）

- ユーザーが入力した文字やCSVの文字を画面に出すときは、必ず `escapeHtml()` を通す
  （`<` などの記号がHTMLの命令として動いてしまうのを防ぐため）
- 消す操作（入出金・口座・全データ）は、必ず画面の中で「本当に削除しますか」を確認する
- サンプル表示中は保存しない
